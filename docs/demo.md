# Three-minute demo

1. Start the server and load **Behaviour Change**, seed 7.
2. Step several scans. Inspect selected band, time window, dwell, overlap, and conditional MISS update.
3. Continue beyond 40 ms. At B4/B8 unexpected detections, review the surprise event, evidence decay, and recovery/exploration mode.
4. Check candidate ranking and discovery risk; inspect posterior history and stale evidence in Hypotheses.
5. Export the generated exclusion certificate JSON.
6. Run baseline comparison. Metrics come from six paired seed runs of the selected scenario.
